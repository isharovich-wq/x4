# X4: Foundations Utilities & Database — русская локализация (форк)

Форк проекта [crissian/x4](https://github.com/crissian/x4) (сайт [x4-game.com](http://www.x4-game.com)):
калькулятор станций и база данных по X4: Foundations. В этой ветке (`ru-localization`) сайт можно собрать
на русском языке и разместить у себя, например на NAS Synology.

Оригинальный проект и вся база данных принадлежат его автору. Здесь добавлены только средства локализации.

## Что изменено по сравнению с оригиналом

- В HTML-шаблонах расставлены метки перевода Angular (`i18n`), так что **все** видимые надписи попадают в языковой пакет.
  Исправлены три места, где метка `i18n` указывала на чужой идентификатор («Ships», «Add Modules», «Import»).
- Добавлен русский языковой пакет `src/i18n/messages.ru.xlf` и настройка локали `ru` в `angular.json`.
- Добавлены скрипты (Python, запускаются в Docker, ставить Python на компьютер не нужно):

| Файл | Назначение |
|---|---|
| `xlf_translate.py` | создаёт/обновляет языковой пакет `src/i18n/messages.<язык>.xlf` из `messages.xlf` и глоссария |
| `glossary.ru.json` | русский глоссарий: английский текст → перевод |
| `i18nize_templates.py` | расставляет метки `i18n` в шаблонах (в этой ветке уже применён) |
| `x4_localize.py` | берёт **официальные** русские названия и описания из установленной игры и подставляет их в файлы данных |

Файлы данных (`src/app/shared/services/data/*.ts`) в репозитории остаются английскими. Русские тексты из игры
принадлежат Egosoft, поэтому их каждый раз подставляет локальный скрипт, а в репозиторий они не попадают.

## Что понадобится

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (на Windows нужна включённая виртуализация и WSL2);
- [Git](https://git-scm.com/);
- для официальных названий из игры: установленная X4: Foundations (читается только чтение, игра не изменяется);
- для размещения на NAS: Synology с пакетом Web Station (подойдёт любой статический веб-сервер).

Команды ниже даны для PowerShell (Windows). В bash вместо `${PWD}` пишите `$(pwd)`.

## Быстрый старт

### 1. Скачать проект

```
git clone -b ru-localization https://github.com/isharovich-wq/x4.git
cd x4
```

### 2. (по желанию) Подставить официальные русские тексты из игры

Укажите свой путь к папке игры (в Steam: правая кнопка по игре → Управление → Просмотреть локальные файлы):

```
docker run --rm -v "g:\SteamLibrary\steamapps\common\X4 Foundations:/game:ro" -v "${PWD}:/app" -w /app python:3.12 python x4_localize.py /game
```

Скрипт читает архивы `.cat`/`.dat` (базовая игра и официальные DLC `ego_dlc_*`, моды пропускаются), строит таблицу
«английский текст → русский текст» и заменяет поля `name` и `description` в файлах данных. Оригиналы сохраняются
как `*.orig` (в git они игнорируются), отчёт о том, что осталось без перевода, пишется в `x4-localize-report.txt`.

Если пропустить этот шаг, названия модулей, товаров, кораблей и описания останутся английскими, а интерфейс будет русским.

### 3. Собрать сайт

```
docker run --rm -v ${PWD}:/app -w /app node:18 sh -c "npm install && npx ng build --configuration=production,ru"
```

Нужен именно Node 18 (проект на Angular 15). Результат сборки: `dist/x4-ru/ru`.

### 4. Проверить локально

```
docker run --rm -p 8080:80 -v ${PWD}/dist/x4-ru/ru:/usr/share/nginx/html:ro nginx:alpine
```

Откройте http://localhost:8080 (после пересборки перезапускайте контейнер и обновляйте страницу по Ctrl+F5).
Если сайт будет лежать не в корне сервера, см. раздел про `baseHref`.

## Размещение на NAS Synology (Web Station)

1. Скопируйте **содержимое** папки `dist/x4-ru/ru` (файлы, а не саму папку) в общую папку NAS, например `web/x4`.
2. Центр пакетов → установите **Web Station**.
3. Web Station → Веб-службы → Создать → «Статический веб-сайт», корневой каталог `web/x4`, сервер Nginx.
4. Веб-порталы → Создать → выберите службу, например порт HTTP 8081 (или откройте сайт по адресу `http://IP-NAS/x4/`).

Особенности:

- **`baseHref`.** В `index.html` стоит `<base href="...">`. Для сайта по адресу `http://IP-NAS/x4/` нужно значение `/x4/`,
  для сайта в корне порта (`http://IP-NAS:8081/`) значение `/`. Задаётся в `angular.json`:
  `i18n → locales → ru → baseHref`. Если страница пустая и в консоли браузера (F12) ошибки 404 на `main…js`,
  дело почти всегда в этом.
- **Ошибка 403.** Дайте системному пользователю `http` право чтения на общую папку `web`
  (Панель управления → Общая папка → Изменить → Права доступа → Системные внутренние пользователи).
- Маршруты сайта используют `#`, поэтому дополнительная настройка `try_files`/fallback на `index.html` не требуется.

## Как устроена локализация

- **Интерфейс** (меню, кнопки, заголовки таблиц): метки `i18n="@@id"` в шаблонах, `src/i18n/messages.xlf` (исходник,
  создаётся `ng extract-i18n`) и `src/i18n/messages.ru.xlf` (русский пакет).
- **Данные игры** (названия и описания кораблей, модулей, товаров, фракций, оборудования): файлы
  `src/app/shared/services/data/*.ts`, переводятся скриптом `x4_localize.py` по текстам самой игры.

### Обновить строки интерфейса

Если шаблоны менялись и появились новые надписи:

```
docker run --rm -v ${PWD}:/app -w /app node:18 sh -c "npx ng extract-i18n --output-path src/i18n --format xlf"
docker run --rm -v "${PWD}:/app" -w /app python:3.12 python xlf_translate.py ru
```

Вторая команда подставит переводы из `glossary.ru.json` и сохранит уже существующие; непереведённые строки будут
перечислены в `xlf-untranslated.ru.txt`. Переведите их в `messages.ru.xlf` (или добавьте в `glossary.ru.json`) и пересоберите сайт.

### Добавить другой язык

1. `python xlf_translate.py de` (в Docker, как выше) создаст `src/i18n/messages.de.xlf`. Переведите `<target>`
   вручную или заполните `glossary.de.json` (формат как у `glossary.ru.json`) и запустите команду ещё раз.
2. В `angular.json` добавьте язык рядом с `ru`:

```json
"i18n": {
  "sourceLocale": "en-US",
  "locales": {
    "ru": { "translation": "src/i18n/messages.ru.xlf", "baseHref": "" },
    "de": { "translation": "src/i18n/messages.de.xlf", "baseHref": "" }
  }
}
```

и в `architect → build → configurations`:

```json
"de": { "localize": ["de"], "outputPath": "dist/x4-de" }
```

3. Соберите: `ng build --configuration=production,de`.

Для названий из игры у `x4_localize.py` сейчас жёстко задан русский (идентификатор языка игры 7, `RU_ID` в начале файла);
для другого языка поменяйте эту константу (например, 49 для немецкого) и пути к файлам данных.

### После обновления игры или проекта

Данные сайта обновляет автор оригинального проекта. Чтобы подтянуть его обновления:

```
git fetch upstream
git merge upstream/dev
```

После слияния удалите устаревшие копии `*.orig`, иначе скрипты возьмут старые версии файлов:

```
Remove-Item src\app\shared\services\data\*.orig
```

и запустите `x4_localize.py` заново (шаг 2), затем пересоберите сайт. Если автор добавил в шаблоны новые надписи
без меток `i18n`, дополните список фраз в `i18nize_templates.py` и повторите расстановку меток.

## Ограничения

- Часть названий и описаний новейших DLC может не найтись в текстах установленной игры (например, названия вариантов
  кораблей вроде «(Gas)», «(Mineral)» и описания кораблей новых DLC): они остаются английскими.
  Полный список написан в `x4-localize-report.txt`.
- Перевод интерфейса подготовлен с помощью ИИ и может содержать неточности. Правки приветствуются.
- Слова с несколькими вариантами перевода в игре (например, «Small», «Large») скрипт переводит самым частым вариантом.
  Спорные случаи перечислены в конце `x4-localize-report.txt`.
